화면 공유 연결 테스트

이 버전은 화면 공유가 작동하는지만 검증합니다. OCR·가격 저장·공유 DB는 아직 없습니다. 캡처 영상과 테스트 이미지는 서버로 전송하지 않습니다.

상태: 대기 중
화면 크기—
테스트 캡처 수0

공유 화면 미리보기

아이온2 거래소가 미리보기에 나오면 1차 테스트 성공! 화면이 검게 나오면 게임의 전체화면 모드를 테두리 없는 창(Borderless)으로 변경하거나 '전체 화면' 공유를 시험해 보세요.

테스트 순서

  1. 아이온2 거래소를 열어둡니다.
  2. 화면 공유 시작 → 게임 창 또는 모니터를 선택합니다.
  3. 미리보기에 거래소 아이템명과 가격이 표시되는지 확인합니다.
  4. 현재 프레임 확인 버튼을 누르면 캡처 이미지가 아래에 표시됩니다.
  5. 공유 종료를 누르면 브라우저 화면 캡처가 중지됩니다.
